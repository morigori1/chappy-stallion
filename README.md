# ◇ チャッピースタリオン（CHAPPY STALLION）v0 プロトタイプ

AIスタートアップのCEOとなり、資金・採用・モデル開発・プロダクト・投資家・M&Aを駆使して **IPO** を目指す、ブラウザで遊べるラウンド制の経営シミュレーションです。見た目はダーク＆ゴールドのテーマです。

## 起動方法

ビルドは不要です（HTML / CSS / JavaScript だけで動きます）。

**方法1：ファイルを直接開く**
`index.html` をブラウザ（Chrome / Edge / Safari / Firefox）にドラッグ＆ドロップするか、ダブルクリックで開きます。

**方法2：ローカルサーバーで開く（任意）**
```bash
cd chappy-stallion
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 遊び方

1. タイトル画面で社名と難易度を選び「はじめる」を押します。
2. **1ターン＝1四半期**です。毎期 **行動力3（◆◆◆）** を使ってアクションを実行します。
3. 「四半期を終える ▶」で決算が行われます（売上 − 人件費・GPU維持費・推論コスト）。ランダムな市場イベントが起き、ライバルのモデルも進化します。
4. IPO条件をすべて満たしたら上場に挑戦しましょう。

| 🏆 ベンチマーク | ライバルと勝負（1期1回）。勝てば評判UP、負ければダウン |

| 🤝 M&A | 毎期出る買収候補・自社より弱いライバルの買収。メガテックからの買収提案を受けて売却することも可能 |

### 勝敗条件
- 🏆 **IPO成功**：勝利
- 🤝 **会社売却**：買収提案を受諾してエグジット
- 💀 **倒産**：資金がマイナス（1回目は緊急ブリッジ融資で救済、2回目で倒産。Q1〜Q8の創業期はさらに1回だけ特例の救済あり）
- 🚪 **CEO解任**：持株比率が8%を下回る
- ⌛ **時間切れ**：10年（40四半期）経過

## ビジュアル
背景には、金色のノードがつながるニューラルネットのアニメーション（canvas）と回路グリッドが描かれます。エンブレムは六角形の中にニューラルネットを描いた「ニューラルコア」（SVG）で、アクションにはSVGアイコンを使っています。

## スマホで遊ぶ
- `chappy-stallion-mobile.html`（CSSとJSを1ファイルにまとめた版）をスマホに送り、ブラウザで開くだけで遊べます。セーブ（ハイスコア）はブラウザごとに保存されます。
  - iPhone：AirDrop またはファイルアプリに保存 → ファイルアプリで開き、共有メニューから Safari で開く
  - Android：Google ドライブなどに保存 → Chrome で開く
- PCと同じWi-Fiにつながっている場合：PCでこのフォルダを開き、`python3 -m http.server 8000` を実行します。スマホで `http://<PCのIPアドレス>:8000/` を開きます。
- GitHub Pages や Netlify Drop にフォルダをアップロードすれば、固定のURLで遊べます。
- 画面幅が640px以下になると、スマホ用レイアウトに切り替わります（1列表示、上部固定のバー、下から出るシート型の判断画面）。


## 序盤バランス（創業期支援）
- 初期資金：イージー10億円／ノーマル7億円／ハード4.5億円
- Q1〜Q4：採用・GPU・学習・広報・新規ローンチ 4割引、人件費 3割引。Q5〜Q8：2割引、人件費15%引き
- Q1〜Q8：受託開発の報酬 +3,000万円、悪いイベントの発生率を Q1〜4 は1/3・Q5〜8 は2/3 に
- Q1〜Q8 の資金ショートは1回だけ特例救済（持株 -15%・評判 -5、通常の救済回数は消費しない）
- ライバルの初期スコアをやや低めに

## ライバル闘争（v0.6）
- ライバル5社：オープンブレイン（拡大至上主義）／ジェミニー（物量の巨人）／アンソロポス（安全性の旗手）／ディープシーカー（低コストの刺客）／メタルAI（札束とオープン戦略）。各社が資金・評判・プロダクト・調達ラウンドを持ち、性格に応じて動く。
- **ライバルのターン**：毎四半期、各社が「次の一手」を事前公開し、四半期末に実行（資金調達／新製品／新モデル／値下げ／ネガキャン／研究者引き抜き／敵対的TOB／上場）。
- **対抗策**：狙われたプロダクトを今期強化すれば迎撃、広報を打てばネガキャン不発、モデルで5点以上リードすれば値下げ無効、休戦協定で攻撃停止。
- **一番乗りレース**：資金調達ラウンド（先着で調達額+10%・評判+3、先を越されると条件悪化）、各プロダクト市場（先着で成長×1.15、遅れるとシェア減）、上場（先着で成功率+8%）。
- **宿敵システム**：因縁ゲージが最も高いライバルが「宿敵」として画面上部に常駐。ベンチマーク勝利で評判ボーナス。
- **リーダーボードのドラマ**：順位の▲▼表示、追い抜き・追い抜かれ・王座奪取／陥落のニュース。評価額ランキング付きの「ライバル戦況」パネル。
- **名指しイベント**：CEOの挑発、公開討論（選択）、ライバルの安全性スキャンダル、内紛で研究者大量離脱（選択）、2社提携、GPU買い占めなど。
- **敵対的買収**：終盤、評価額で大差をつけられると宿敵がTOBを仕掛けてくる。受け入れるとゲーム終了（敵対的買収エンド）。資金が尽きたライバルは業界再編で吸収される。
- **序盤はやさしく**：Q1〜Q4はライバルの直接攻撃なし、Q5〜Q8は攻撃の効果半減・引き抜きは1名まで。


## ベンチマーク・レース（ダービー風デモ）
- 「ベンチマーク」で対戦ライバルを選ぶと、自社＋生存ライバル全モデルが出走するレース演出が始まる（知識→数学→コード→エージェントの4区間、人気・単勝オッズ、実況、着順・タイム・着差の確定板）。
- 勝敗（指名ライバルに先着できるか）は従来と同じ勝率で決まり、展開はスコア＋乱数で生成。総合1着なら評判+2のボーナス。
- 「結果までスキップ」で即確定。

## 調教システム＆厩舎テーマ（v0.8・ダービー風）※v0.9でAIラボ表現に置き換え
- 「モデル学習」→「**調教**」。コース：坂路（短期FT）／ウッド（継続事前学習）／併せ馬（ライバル蒸留・相手に先着で+15%）／長距離追い（巨大学習ラン）／プール（RLHF・疲労回復＋評判+1）／放牧（無料休養・疲労-45）。
- 追い方：馬なり（伸び×0.75・疲労半分・故障率低）／強め（標準）／一杯（伸び×1.3・疲労×1.6・故障率×1.4）。
- **調子**（絶好調↑〜絶不調↓：伸び×1.2〜×0.75）と**疲労**（50超で故障率上昇、四半期ごとに22＋研究者数だけ回復、70以上だと調子落ち）。
- 調教演出：コース走行、追いメーター、loss表示、調教時計（例：坂路4F 51.8-37.6-24.4-12.1）、A/B/C評価、調教師（チーフサイエンティスト）コメント。スキップ可。
- ベンチマーク：パドックで調子表示、調子で勝率±10%・疲労で最大-8%。勝つと調子UP、負けると調子DOWN、出走で疲労+8。
- 厩舎フレーバー：研究者＝調教師、エンジニア＝厩務員、営業＝馬主営業、計算資源＝調教場（拡張で疲労-8）、プロダクト＝重賞路線（新馬戦デビュー）、広報＝取材・パドック（調子+3）、受託開発＝地方遠征（疲労+5）。パネル名：厩舎ダッシュボード／厩舎コマンド／モデル番付／厩舎日誌。
- イベント追加（調教カテゴリ）：夏合宿／調教中のアクシデント／名伯楽が技術顧問に／新しい評価用データ。


## v0.9 — モデル系譜・学会カレンダー・研究者の個性・3つの負荷
馬モチーフを抑え、AIラボらしい要素に置き換えました（厩舎→ラボ、調教→トレーニング、放牧→クールダウン など）。

- **3つの負荷（旧「疲労」）**
  - 計算負荷：高いと学習スループット（伸び）が低下。毎期よく回復、GPU増強で -15
  - 技術的負債：高いと学習の伸びとプロダクト成長が鈍る。自然には抜けにくい → リファクタリング／次世代リリースで返済
  - チーム疲弊：高いほど短期的には速い（最大+20%）が、学習失敗などのミスが増える。クールダウンで回復
- **トレーニング**：スプリントFT／継続事前学習／対抗蒸留／フロンティア学習ラン／RLHF・安全性調整／リファクタリング／クールダウン × 控えめ・標準・全開。結果はチェックポイント評価の「学習ログ」で表示
- **A. モデル系譜**：スコアが前世代+8で次世代 Chappy-N をリリース。親の特性を継承（系統Lv最大3）するか新系統へ。特性＝博識型・推論型・コード型・エージェント型・省電力型・安全志向型（売上・ベンチ区間・負荷・失敗率に効果）
- **B. 学会カレンダー**：Q1 ICLR → Q2 ICML → Q3 ACL → Q4 NeurIPS。「論文投稿」（通常／総力戦）→ 四半期末に査読スコア付きで Reject／Poster／Oral／Best Paper。注目テーマとモデル特性が一致すると有利。ライバルも投稿し、年末に年間論文ランキング
- **C. 研究者の個性**：天才肌・慎重派・職人気質・論文マシン・ムードメーカー・インフラ番長・野心家。名前付きで、各自の効果と状況別セリフ（学習結果・負荷の警告・論文・引き抜き・新世代）がある。研究者をまとめて採用すると加入、引き抜きで去ることも
- 画面に「モデル系譜」「研究チーム」「学会カレンダー」パネルを追加
